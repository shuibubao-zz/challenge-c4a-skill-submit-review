# Demo：一条命令，一份报告

> 本 Demo 展示**真跑出来的输出**，不是示意图。两条命令、两份产物，**约 1 分钟**。

---

## 0. 前置

```bash
python --version    # 3.9+
```

零强制依赖（有 PyYAML 用 PyYAML，没有用内置解析器），`openpyxl` 可选（装了才出 Excel，没装不影响 Demo）。

---

## 1. 命令一：评审一份真实技能提交

```bash
python c4-skill-evaluator/scripts/c4_evaluator.py evaluate \
    "C4A/_starter/c4a-skill-evaluator-starter" \
    --out ./demo_out
```

**真实输出** → `sample_output_官方starter评审.md`

看什么：
- 「班级总览」：几份提交、最常见缺什么、最弱维度
- 「作者详情 → 完整性检查」：5 个槽位逐一列出，**带匹配文件名和判定方式**
- 「质量评审（四条件）」：**看"依据"列**——那是证据锚点（`SKILL.md:78` 或 `未发现：…`）
- 「改进建议」：可执行动作，不是套话

---

## 2. 命令二：测评审器自己的误判率

```bash
python c4-skill-evaluator/scripts/golden_test.py --out ./demo_out/golden.txt
```

**真实输出** → `sample_output_黄金集实测.txt`

看什么：
- 完整性判定准确率、质量评级精确匹配率、**严重误判率**
- 「残留差异」一节：所有判错的项**全部列出**，不做选择性汇报
